📘 Lección 1: ¿Qué es JavaScript?

JavaScript es un lenguaje de programación de alto nivel, interpretado, 
orientado a objetos y esencial para el desarrollo web frontend. 
Se ejecuta en el navegador y permite hacer páginas web interactivas.

📌 ¿Para qué sirve?

- Manipular el contenido del DOM (Document Object Model)

- Validar formularios

- Crear animaciones

- Detectar eventos (clics, movimientos del ratón, etc.)

- Conectarse con APIs

Y mucho más...

🧠 Conceptos clave de esta lección

1. Cómo se integra JavaScript en una web:

``` 
<!-- Forma externa (recomendada) -->
<script src="script.js"></script>

<!-- Forma interna (no recomendada para proyectos grandes) -->
<script>
  console.log("Hola desde dentro del HTML");
</script>

```
